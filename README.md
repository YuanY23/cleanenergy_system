# 面向零碳工业园区的电—热—氢—储系统规划与韧性评估

> 当前唯一有效成果入口：[交付成果/最新项目/README.md](交付成果/最新项目/README.md)
> 当前正式运行：`formal-2024-20260809T131238Z`（状态：`complete`）

本项目面向能源央国企的新能源规划、综合能源协同、全年运行校核、极端工况保供和能碳核算工作，构建园区级电—热—氢—储一体化优化模型。项目不做交互式展示系统，重点是形成一套可审计、可复现、能解释工程取舍的规划与校核闭环。

## 当前结论

- 以 2024 年闰年 8,784 小时为统一时序边界，ERA5 为生产气象数据，NASA POWER 仅用于月度独立校核。
- 以 31 亿 kWh/年、450 MW 峰值为园区电负荷校准尺度；热负荷和氢负荷属于有界工程假设，不表述为企业 SCADA 实测值。
- 选取 12 个真实代表日进行容量规划，再以固定容量完成三类方案各 8,784 小时连续滚动回放。
- 经济型、低碳型、韧性型的年化总成本分别为 17.01、18.71、17.65 亿元/年；位置法运行碳排分别为 185.48、120.28、170.42 万吨 CO₂/年。
- 三类方案正常年回放 ENS 均为 0；另对每类方案完成 18 个、合计 54 个确定性孤网与设备故障事件测试。

以上数字只能与本次正式运行标识同时引用。低碳型在时间上限内取得可行解，实际 MIP gap 为 1.335%，不能表述为严格全局最优；可靠性结论属于确定性压力测试，不构成认证或概率风险承诺。

## 技术实现

```text
src/zero_carbon_park/
├── data/             # 来源注册、ERA5处理、负荷重构与质量门
├── typical_days/     # 真实代表日、极端日、366日映射与跨期链接
├── planning/         # 统一物理约束与三类容量方案
├── replay/           # 固定容量的全年滚动回放
├── reliability/      # 孤网及设备故障确定性压力测试
├── reporting/        # 双口径能碳指标、静态图表与技术报告
└── optimization/     # HiGHS 求解与复现元数据
```

环境要求为 Python 3.12+，核心技术包括 pandas、pvlib、xarray、Pyomo 与 HiGHS。数据方法及字段级来源见[数据方法说明](docs/data_methodology.md)。
