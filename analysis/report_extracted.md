# 以典型零碳园区为背景的电-热-氢-储综合能源系统优化调度仿真项目研究报告

## 一、项目研究目的

本项目面向零碳园区、综合能源站和风光储氢一体化系统建设需求，拟构建一个包含新能源发电、电化学储能、氢能系统、热力系统和外部电网的综合能源系统优化调度模型。项目的核心目标是研究在典型园区能源需求场景下，风电、光伏、电储能、电解槽、储氢罐、燃料电池、热泵和燃气锅炉等设备如何协同运行，以实现新能源消纳率提升、系统运行成本降低和碳排放减少。

本项目并不依赖线下实验设备，而是通过公开数据、典型负荷曲线、设备技术经济参数和优化调度模型进行仿真分析。通过该项目，可以体现清洁能源技术、能源动力工程、综合能源系统建模、优化调度、低碳经济性分析和
Python 仿真编程等方面的综合能力。

具体研究目的包括：

1.  构建典型零碳园区电-热-氢-储综合能源系统结构模型；
2.  建立风电、光伏、电负荷、热负荷、氢负荷等基础数据体系；
3.  建立电储能、电解槽、储氢罐、燃料电池、热泵、燃气锅炉等设备运行模型；
4.  构建电、热、氢多能流平衡约束；
5.  建立以系统综合运行成本最低为目标的优化调度模型；
6.  分析储能、绿氢、热泵和碳价机制对系统经济性、低碳性和新能源消纳能力的影响；
7.  形成适合研究院、设计院、新能源公司简历展示的仿真项目成果。

## 二、项目整体介绍

### 1. 项目背景选取

本项目以"典型零碳园区"为工程背景。该园区可以参考现实中的零碳产业园、风光氢储一体化园区、综合能源示范区或工业园区低碳用能场景，但不声称使用某一真实园区的完整运行数据。

推荐表述为：

> 本项目以典型零碳园区为背景，参考风光储氢一体化园区的能源利用模式，结合公开新能源出力数据、典型园区负荷曲线和设备技术经济参数，构建电-热-氢-储综合能源系统优化调度模型。

这种方式既有真实工程场景，又避免了没有企业真实数据的问题。

### 2. 数据来源与构造方式

本项目数据由三部分组成：

第一类是公开新能源出力数据，包括风电出力数据和光伏出力数据。可以使用公开风光资源数据、典型日曲线、仿真生成数据或开源能源数据集，形成
24 小时或 8760 小时新能源出力曲线。

第二类是典型园区负荷数据，包括电负荷、热负荷和氢负荷。电负荷可以采用典型工业园区或商业园区日负荷曲线；热负荷可以根据供暖、生活热水或工业热需求构造；氢负荷可以设置为园区氢燃料车、工业用氢或外供氢需求。

第三类是设备技术经济参数，包括储能容量、储能效率、电解槽效率、燃料电池效率、储氢罐容量、热泵
COP、燃气锅炉效率、购电价格、天然气价格、碳排放因子、碳价、设备运维成本和弃风弃光惩罚成本等。

### 3. 仿真系统整体结构

本项目综合能源系统主要包括以下部分：

1.  新能源发电系统：风电、光伏；
2.  电力系统：外部电网、电负荷、电化学储能；
3.  氢能系统：电解槽、储氢罐、燃料电池、氢负荷；
4.  热力系统：热泵、燃气锅炉、热负荷；
5.  碳排放系统：电网购电间接碳排放、燃气锅炉直接碳排放；
6.  经济系统：购电成本、天然气成本、设备运维成本、弃电惩罚、碳排放成本、售氢收益。

系统运行逻辑为：

风电和光伏优先满足园区电负荷。当新能源出力大于电负荷时，多余电量可以用于电储能充电、电解槽制氢或热泵供热；当新能源出力不足时，可以由电储能放电、燃料电池发电或外部电网购电补充。热负荷由热泵和燃气锅炉共同满足，氢负荷由电解槽制氢和储氢罐放氢满足。系统通过优化调度决定每个时刻各设备的运行状态和出力。

## 三、项目使用的技术、模型与约束

### 1. 技术路线

本项目建议采用 Python 作为主要开发语言，使用 Pandas 和 NumPy
进行数据处理，使用 Matplotlib 绘制仿真结果图，使用 Pyomo 或 PuLP
建立优化模型，调用 HiGHS、CBC 或 Gurobi 等求解器求解优化问题。

推荐技术组合为：

1.  Python：项目主体开发；
2.  Pandas：读取和处理风光出力、负荷、电价等时间序列数据；
3.  NumPy：数值计算；
4.  Matplotlib：结果可视化；
5.  Pyomo：建立优化调度模型；
6.  HiGHS / CBC / Gurobi：求解 LP 或 MILP 模型；
7.  Excel / CSV：输入数据和输出结果管理。

### 2. 推荐模型

本项目推荐采用：

> 确定性日前优化调度模型 + 混合整数线性规划 MILP 模型。

其中，"日前优化调度"表示以 24
小时时间尺度，提前给定风光出力预测、负荷需求和电价等数据，优化计算每个时段各类设备的运行策略。

"MILP 模型"适合描述设备启停、储能充放电状态、电解槽运行状态等问题。

### 3. 优化目标

本项目的优化目标为系统综合运行成本最低。

目标函数包括：

1.  电网购电成本；
2.  天然气消耗成本；
3.  设备运行维护成本；
4.  弃风弃光惩罚成本；
5.  碳排放成本；
6.  可选的售氢收益。

目标函数可表达为：

> 系统总成本 = 购电成本 + 天然气成本 + 设备运维成本 + 弃电惩罚成本 +
> 碳排放成本 - 售氢收益

该目标函数能够同时体现经济性和低碳性。

### 4. 主要约束条件

#### 4.1 电力平衡约束

每个时刻，系统发电和购电必须满足电力需求、电储能充电、电解槽制氢耗电和热泵耗电。

电力来源包括：

1.  风电利用功率；
2.  光伏利用功率；
3.  电储能放电功率；
4.  燃料电池发电功率；
5.  外部电网购电功率。

电力去向包括：

1.  园区电负荷；
2.  电储能充电功率；
3.  电解槽耗电功率；
4.  热泵耗电功率；
5.  可选的外送电功率。

#### 4.2 热力平衡约束

每个时刻，热泵供热和燃气锅炉供热需要满足园区热负荷需求。

热力来源包括：

1.  热泵供热；
2.  燃气锅炉供热；
3.  可选的储热罐放热。

热力去向包括：

1.  园区热负荷；
2.  可选的储热罐充热。

基础版本可以暂时不设置储热罐，只保留热泵和燃气锅炉。

#### 4.3 氢能平衡约束

每个时刻，电解槽制氢和储氢罐放氢需要满足氢负荷、燃料电池耗氢和储氢罐充氢需求。

氢气来源包括：

1.  电解槽制氢；
2.  储氢罐放氢。

氢气去向包括：

1.  园区氢负荷；
2.  燃料电池耗氢；
3.  储氢罐充氢；
4.  可选的外售氢气。

#### 4.4 电化学储能约束

储能系统需要考虑：

1.  储能容量上限和下限；
2.  储能 SOC 动态变化；
3.  最大充电功率；
4.  最大放电功率；
5.  充电效率；
6.  放电效率；
7.  初始 SOC 和末端 SOC；
8.  可选的同一时刻不能同时充电和放电约束。

储能 SOC 变化逻辑为：

> 下一时刻 SOC = 当前 SOC + 充电功率 × 充电效率 - 放电功率 / 放电效率

#### 4.5 储氢罐约束

储氢罐需要考虑：

1.  储氢容量上限和下限；
2.  储氢量动态变化；
3.  最大充氢速率；
4.  最大放氢速率；
5.  初始储氢量和末端储氢量。

储氢量变化逻辑为：

> 下一时刻储氢量 = 当前储氢量 + 充氢量 - 放氢量

#### 4.6 电解槽约束

电解槽需要考虑：

1.  最大运行功率；
2.  最小运行功率；
3.  制氢效率；
4.  电解槽耗电量与产氢量关系；
5.  可选的启停状态。

简化关系为：

> 产氢量 = 电解槽耗电功率 × 制氢效率

#### 4.7 燃料电池约束

燃料电池需要考虑：

1.  最大发电功率；
2.  发电效率；
3.  耗氢量与发电量关系；
4.  可选的启停状态。

简化关系为：

> 燃料电池发电量 = 耗氢量 × 发电效率

#### 4.8 热泵约束

热泵需要考虑：

1.  最大耗电功率；
2.  COP；
3.  耗电量与供热量关系。

简化关系为：

> 热泵供热量 = 热泵耗电量 × COP

#### 4.9 燃气锅炉约束

燃气锅炉需要考虑：

1.  最大供热功率；
2.  锅炉效率；
3.  天然气消耗量；
4.  碳排放量。

燃气锅炉供热会带来天然气成本和直接碳排放。

#### 4.10 新能源利用与弃电约束

风电和光伏出力不能超过其可发功率。

风电关系为：

> 风电利用功率 + 弃风功率 = 风电可发功率

光伏关系为：

> 光伏利用功率 + 弃光功率 = 光伏可发功率

弃风弃光量越低，说明系统新能源消纳能力越强。

#### 4.11 碳排放约束

系统碳排放主要包括：

1.  外部电网购电对应的间接碳排放；
2.  燃气锅炉燃烧天然气产生的直接碳排放。

碳排放成本为：

> 碳排放成本 = 碳排放量 × 碳价

通过设置碳价，可以分析碳约束对系统调度策略的影响。

## 四、项目场景设计

为了体现项目深度，需要设置多个对比场景。建议至少包括以下场景：

1.  传统供能场景：外部电网购电 + 燃气锅炉供热；
2.  新能源接入场景：加入风电和光伏；
3.  新能源 + 电储能场景：加入电化学储能；
4.  新能源 + 电储能 + 制氢场景：加入电解槽和储氢罐；
5.  新能源 + 电储能 + 制氢 + 燃料电池场景：加入氢转电路径；
6.  低碳调度场景：引入碳价机制；
7.  不同碳价场景：分析碳价变化对调度策略和碳排放的影响；
8.  不同氢价场景：分析绿氢经济性；
9.  不同储能容量场景：分析储能配置对系统经济性和新能源消纳的影响；
10. 不同新能源渗透率场景：分析高比例新能源接入下系统运行变化。

每个场景输出以下指标：

1.  系统总运行成本；
2.  购电成本；
3.  天然气成本；
4.  设备运维成本；
5.  弃风弃光量；
6.  新能源消纳率；
7.  碳排放量；
8.  碳排放成本；
9.  电储能利用情况；
10. 制氢量和储氢量；
11. 热泵和燃气锅炉供热比例。

## 六、后续可升级方向

本项目基础版本完成后，可以从以下方向继续升级。

### 1. 从日前优化升级为滚动优化

基础版本采用日前优化，即提前给定一天或一年的风光出力和负荷数据，然后一次性优化。后续可以升级为滚动优化，每隔若干小时更新预测数据并重新优化，更接近真实调度过程。

### 2. 从确定性模型升级为不确定性模型

基础版本假设风光出力和负荷数据已知。后续可以考虑风电、光伏和负荷预测误差，引入随机优化或鲁棒优化，分析新能源不确定性对系统运行策略的影响。

### 3. 从单目标优化升级为多目标优化

基础版本以系统综合运行成本最低为目标。后续可以同时考虑：

1.  系统运行成本最低；
2.  碳排放量最低；
3.  新能源消纳率最高；
4.  设备运行稳定性更好。

可以通过加权法或 Pareto 分析进行多目标优化。

### 4. 从运行优化升级为容量配置优化

基础版本主要优化设备运行调度。后续可以进一步把风电容量、光伏容量、储能容量、电解槽容量、储氢罐容量、燃料电池容量和热泵容量作为决策变量，开展容量配置与运行调度联合优化。

### 5. 加入储热系统

基础版本热力系统只考虑热泵和燃气锅炉。后续可以加入储热罐，使热能也具备时间转移能力，进一步提升新能源消纳能力。

### 6. 加入需求响应

后续可以将部分电负荷、热负荷或氢负荷设置为可转移负荷，研究需求响应对系统经济性和低碳性的影响。

### 7. 加入电力市场和辅助服务收益

后续可以考虑分时电价、峰谷价差、绿电交易、碳交易、储能参与调峰调频收益等机制，使项目更贴近实际工程应用。

### 8. 加入真实园区案例校准

如果后期能够获得某一园区的真实负荷、设备容量或运行数据，可以用真实数据替换典型数据，对模型进行校准，提高项目工程可信度。

## 七、项目总结定位

本项目本质上是一个面向零碳园区的综合能源系统优化调度仿真项目。项目通过构建电、热、氢、储多能流耦合模型，研究风光新能源、电化学储能、绿氢系统、热泵和燃气锅炉之间的协同运行关系，分析不同设备配置和政策机制对系统运行成本、碳排放水平和新能源消纳率的影响。

该项目的核心价值不在于单纯使用某一个复杂算法，而在于能够将清洁能源、储能、氢能、热力系统、碳排放核算和优化调度方法结合起来，形成一个完整、可计算、可解释、可拓展的能源系统仿真研究框架。

该项目适合作为清洁能源技术、能源动力工程、新型电力系统、综合能源、氢能与储能、低碳园区规划等方向的研究生简历项目，也适合投递五大发电集团研究院、六小发电集团研究院、中核中广核新能源平台、中国电建和中国能建设计院等单位时进行展示。
