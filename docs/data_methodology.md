# 数据来源、假设与口径方法

## 1. 目的与证据边界

本项目研究对象是公开数据驱动的零碳工业园区重构算例，不是某一园区的
SCADA实测复刻。输入证据按以下顺序使用：正式政策或标准、官方数据集、
国际技术与成本基准、公开尺度校准、工程情景假设。ERA5属于再分析数据，
NASA POWER属于独立校核数据，Global Wind Atlas属于长期资源校准参考；
三者均不表述为园区实测。

字段级来源登记在 `data/metadata/source_registry.csv`，工程假设及其上下界登记
在 `data/metadata/assumptions.yaml`。正式运行清单只引用 `data/raw/` 和
`data/processed/` 中的明确文件，并另外固定这些文件的SHA256。根目录工作簿、
`outputs/` 和历史结果不属于正式输入。

## 2. 注册表生命周期

来源注册表至少记录字段名、来源ID、来源类别、官方URL、发布日期、获取日、
原始和目标单位、时区、处理方法、换算公式、原文件SHA256、适用期、可信度、
备注及主来源标记。

当前登记表是下载前的来源计划。尚未重新下载的远端资料明确使用
`PENDING_DOWNLOAD`；计划阶段尚未从正文核验的日期使用
`PENDING_VERIFICATION`。这些标记不是文件哈希或日期，也不得进入正式运行。
下载管道应在保存原始文件后计算真实的64位小写SHA256，将记录标记为
`verified`，再调用 `SourceRegistry.validate_for_formal_run()`。这样既不伪造哈希，
也能让正式发布门拒绝未完成的来源记录。

同一字段可以保留校核来源，但在任一适用日期只能存在一个主来源。政策参数
必须在其生效区间内查询；发现后续政策时，应新增不重叠的记录，不能直接覆盖
历史版本。

## 3. 8784小时气象口径

生产气象源为ERA5小时单层数据，使用2 m气温、地表太阳辐射和100 m风速分量。
管道保留原始UTC时间，再转换为 `Asia/Shanghai` 本地标准时；为完整覆盖2024年
本地时间，需要请求年界额外UTC小时。最终主表必须从2024-01-01 00:00连续到
2024-12-31 23:00，共8784个唯一小时。

NASA POWER只进行月度分布交叉检查，不拼接或替换ERA5小时序列。Global Wind
Atlas只用于年度风资源偏差系数和敏感性，不改变原始小时排序。太阳辐射从
J/m²每小时换为W/m²时除以3600，温度从K换为摄氏度时减273.15；所有换算公式
均保留在注册表中。

## 4. 合成负荷与工程假设

电、热、氢负荷均标记为 `engineering_assumption`。每个假设必须满足
`lower_bound <= base_value <= upper_bound`，并记录单位、理由、可信度和相关证据
来源。电负荷采用鄂尔多斯市政府公开的2024年园区新能源企业用电31亿kWh作为
年度尺度。按8784小时和0.786工程负荷率推导峰值449.0 MW，基准取450 MW，并
保留225/450/675 MW（50%/100%/150%）敏感性。该公开值只校准年度量级；小时
曲线仍是基荷、工作日、班次和温度分量构成的合成场景，不得写成“采集了真实
园区负荷”或SCADA复刻。

后续负荷重构将分别公布电负荷的工业基荷、工作日和温度分量，热负荷的工艺
基荷与采暖度时分量，以及氢负荷的连续和可中断任务分量。月度统计、峰值、年
总量和负荷持续曲线用于验证校准目标。

热负荷基准设置为115万MWh_th/年、270 MW_th峰值，按工艺基荷与18摄氏度采暖
度时重构；氢负荷设置为3万kg/日，其中70%为连续任务、30%为10:00—18:00可
中断任务。两者均为可配置工程假设，并执行50%/100%/150%规模敏感性。

## 5. 技术经济参数

蒙西分时电价、第四监管周期输配电价、需量或容量费、线损率和鄂尔多斯非居民
天然气价按政策适用日期选择。电压等级、地区和计费方式必须进入配置，不能在
代码中隐含选择。IRENA风光储造价和IEA/DOE电解槽数据仅作国际基准；汇率和
本地化系数作为有上下界的工程假设单独展示，不能把国际均值表述为国内项目
报价，也不能把远期技术目标当作当前设备性能。

本算例电网侧明确假定蒙西110 kV两部制、按需量计费：第四监管周期输配电价
0.0520元/kWh、需量费31.2元/kW·月、线损率2.81%；容量计费19.5元/kVA·月仅为
配置备选，两者不叠加。分时比例按大风季1.48:1:0.79、小风季1.48:1:0.47执行，
6—8月18:00—20:00在峰段基础上再上浮20%。鄂尔多斯非居民气价2.952元/m³只
适用于2026-04-01至2026-10-31，超出日期时程序拒绝静默沿用并要求显式场景。

## 6. 两套碳核算严禁混算

企业核算的位置法范围二使用内蒙古省级电力因子，当前待正式核验值为
0.6479 kgCO2/kWh。国家级零碳园区口径使用相应核算方法，当前待正式核验的
化石能源电力因子为0.8325 kgCO2/kWh，符合条件的直供非化石电力和绿电单独按
零因子列示。两个结果分别输出，不能在同一公式中挑选更有利的因子；外送电也
不直接抵扣企业位置法购电排放。

天然气范围一排放由适用核算指南中的低位热值、单位热值含碳量、氧化率和
44/12分子量换算逐项计算。注册表目前只固定了生态环境部指南入口，正式运行前
必须由U4固定具体指南文件、版本、参数页码和原文件SHA256。

## 7. 可靠性与方法来源

GB/T 29328-2018的应急电源配置要求仅作为工程对标，项目不声称通过标准认证。
在没有故障概率和用户停电统计时，事件结果只报告ENS、失供小时、关键负荷
供能率、最大连续失供时长、最低SOC和孤网生存时长，不使用EENS、LOLP、
SAIDI或SAIFI名称。代表时段的跨期库存连接以Kotzur等人的季节储能方法为
依据，并通过固定容量8784小时全年回放验证。

## 8. 正式发布检查

正式结果发布前至少检查：

1. 注册表不存在pending标记，全部主来源具有真实原文件SHA256；
2. 每个输入字段在研究时点有且仅有一个有效主来源；
3. 政策日期、地区、电压等级和计费口径与配置一致；
4. 工程假设均有上下界，且从未标为实测；
5. 0.6479和0.8325两套电力碳因子分别计算和列示；
6. 运行清单中的文件哈希与实际文件一致，历史结果路径未被引用。
