# 开发与正式研究入口

本页已替代旧版 24 小时 Excel/S0—S5 开发说明。旧方法只保留在历史归档中，不再作为当前项目的使用指南。

## 当前权威入口

- 项目与成果索引：[最新项目 README](../交付成果/最新项目/README.md)
- 全量研究说明：[项目研究报告](../交付成果/最新项目/项目研究报告.md)
- 运行、验证和更新：[复现与更新指南](../交付成果/最新项目/复现与更新指南.md)
- 数据来源与假设：[数据方法说明](data_methodology.md)
- 机器可读当前版本：[LATEST_PROJECT.json](../交付成果/最新项目/LATEST_PROJECT.json)

## 开发原则

1. 正式研究只能从显式 manifest 进入，不能扫描历史输出，也不能自动读取根目录旧 Excel。
2. 每次正式运行必须使用新的 `run_id`，输出到 `artifacts/runs/<run_id>/`；成功通过全部质量门后才允许更新 `artifacts/latest.json`。
3. 规划、全年回放和可靠性测试共用同一物理约束；固定容量回放不得偷偷重选容量。
4. 模型结果、公开事实和工程假设必须分开描述；合成负荷不得写成企业实测数据。
5. 历史目录与失败运行只用于排错追溯，禁止进入新报告和简历数字。

完整命令、质量门和新版本发布步骤见[复现与更新指南](../交付成果/最新项目/复现与更新指南.md)。
