## 2. 时轴与气象质量

- 年份：2024（闰年）。
- 本地小时数：8,784。
- ERA5 主输入从覆盖本地全年所需的 UTC 窗口读取，再转换到本地时区。
- 质量检查包括：小时数、时间戳唯一、连续、无缺失、数值范围、闰年一致性。
- ERA5 原始文件在正式清单中有 SHA-256；已记录的哈希前缀为 `4afb5...`，完整值应以 `manifest.json` 为准。

NASA POWER 对 ERA5 的月度交叉校核：平均太阳辐照绝对偏差约 5.38%，平均温度绝对偏差约 0.69°C。风速高度口径不一致，因此不能把 NASA 风速偏差当成 ERA5 100 m 风速的同尺度误差。

## 4. 负荷形状参数

### 电负荷

- 工作日增量：0.10；
- 班次：08:00—17:00 为 1.0，17:00—24:00 为 0.55，其余为 0.18；
- 班次权重：0.24；
- 温度驱动权重：0.10；
- 温度驱动同时包含采暖和 0.55 权重的制冷项。

### 热负荷

采用 18°C 平衡温度的供热度驱动，再校准到 1.15 TWhth 和 270 MWth。

### 氢负荷

70% 作为全天连续任务均匀分配，30% 作为 10:00—18:00 的可中断生产任务。注意：事件模型中的氢失供变量是供给不足的松弛，不应和“30% 可中断形状份额”混成一个概念。

## 5. 分时电价

代码首先计算能量电价 `0.35 × TOU乘数`，加输配电价 0.052 元/kWh，再按线损率 2.81% 折算：

\[
p_t=\frac{0.35m_t+0.052}{1-0.0281}.
\]

夏季（6—8 月）和其他月份使用不同峰谷时段及倍率；夏季峰/平/谷倍率为 1.48/1.0/0.47，其他季节谷倍率 0.79，18:00—20:00 另有 1.2 倍上浮逻辑。准确分段见 [`mengxi_tou_band()`](../src/zero_carbon_park/planning/cost_params.py) 和 [`mengxi_tou_multiplier()`](../src/zero_carbon_park/planning/cost_params.py)。

配置还保存需量电费 31.2 元/kW·月和容量电费 19.5 元/kVA·月，但正式 `PlanningCostParams` 的年需量成本系数为 0，所以正式成本表 `annual_demand_charge_cost_cny=0`。

## 10. 惩罚参数与含义

| 项 | 参数 | 目的 |
|---|---:|---|
| 关键电负荷失供 | 100,000 元/kWh | 强烈优先保障 |
| 重要电负荷失供 | 10,000 元/kWh | 次级保障 |
| 可中断电负荷失供 | 1,000 元/kWh | 最先允许削减 |
| 氢失供 | 100,000 元/kg | 避免无必要缺氢，同时允许极端事件可解 |
| 外购氢 | 1,000 元/kg | 作为昂贵兜底；韧性型禁用 |
| 弃风弃光 | 0.01 元/kWh | 轻度抑制弃电，不是硬消纳约束 |

惩罚值体现工程优先级，不代表真实停产损失已经由企业财务验证：`【需要项目作者补充】`。

## 11. 参数追溯方法

面试被问“这个数哪来的”时按以下顺序回答：

1. 先说明它是公开数据、来源参数还是工程假设；
2. 指向 `source_registry.csv` 或 `assumptions.yaml`；
3. 指向正式 run 的 `inputs/device_params.csv` 或 `economic_params.csv`；
4. 指向消费它的 `builder.py`/`constraints.py`/`objective.py`；
5. 最后指出它如何影响 `planning_summary.csv`、回放或可靠性结果。
