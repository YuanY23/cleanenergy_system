这是本项目唯一允许用于学习、汇报、简历和面试准备的成果目录。该版本研究的是“零碳工业园区电—热—氢—储系统容量规划、8,784 小时全年运行回放与孤网保供可靠性评估”，不再沿用旧版 S0—S5 或单日展示叙事。

## 一句话结论

在公开尺度校准的 450 MW、31 亿 kWh/年园区算例上，项目用 12 个真实代表日完成三类容量规划，再以三套固定容量分别进行 8,784 小时连续回放和 18 类确定性故障事件验证；结果表明，低碳型以约 10% 年化成本增量换取约 35.15% 的位置法运行碳减排，韧性型以约 3.76% 成本增量降低约 12.7% 的最坏事件总 ENS，但仍不能保证所有孤网场景下关键负荷和氢需求完全供应。

## 使用边界

正式运行结果已完整生成，但“完整”不等于“所有设计目标均满足”：三类方案正常年 ENS 都为 0，而孤网事件中仍存在失供；12 代表日通过年度误差门但未通过月度误差门，因此最终结论必须以 8,784 小时回放为准；低碳型在求解时间上限内保留了可行解，不声称严格全局最优。详见[项目研究报告](项目研究报告.md)。
