# 项目介绍

## 项目名称

面向零碳工业园区的电—热—氢—储系统规划与韧性评估

## 30 秒介绍

我围绕能源企业在零碳园区规划中关心的“装多少、怎么运行、全年能不能跑、停电时能保多久、碳排怎么核算”五个问题，构建了电—热—氢—储综合能源优化模型。项目基于 2024 年 8,784 小时 ERA5 气象和公开园区尺度重构负荷，先用真实代表日完成经济型、低碳型、韧性型容量规划，再固定容量进行全年滚动回放和 54 个孤网/故障事件压力测试，最终形成成本、容量、位置法碳排、零碳园区核算口径和 ENS 等可审计结果。

## 2 分钟介绍

这个项目不是做一个展示界面，而是模拟能源规划岗位的一条完整技术链。研究对象是一个 450 MW 峰值、年用电 31 亿 kWh 的园区级合成算例，系统包含风电、光伏、电网、电池、电解槽、储氢、燃料电池、热泵和燃气锅炉。

在数据层，我把 ERA5 的 2024 年逐时气象转换成风光出力，并用 NASA POWER 做月度独立校核；负荷按公开园区规模构造，明确区分公开事实、模型结果和工程假设。在规划层，我没有直接用 8,784 小时做大规模混合整数容量优化，而是从 366 个真实日中选出 12 个代表日，并强制保留峰荷、低风光等极端日，再保存全年映射和状态链接。三类方案使用同一套物理约束：经济型最小化年化总成本；低碳型在经济型成本 110% 以内最小化运行碳排；韧性型增加保安负荷和 4 小时电池等工程筛选约束。

规划完成后，我把容量固定，采用 336 小时展望、168 小时提交的滚动方式完成每个方案 8,784 小时回放，连续传递电池 SOC 和储氢库存。三类方案正常年 ENS 均为 0。随后从全年实际运行状态启动 2/4/8/24 小时停电、低风光和设备故障事件，共 54 个事件，量化总 ENS、关键负荷供能率、连续失供和供氢率。

结果显示：低碳型年化成本较经济型增加约 10%，位置法运行碳排下降约 35.15%；韧性型成本增加约 3.76%，最坏事件总 ENS 相比经济型下降约 12.7%。同时，结果也说明“配置储能”不等于“所有孤网事件都能完全保供”，前置 SOC、事件时刻和氢库存会显著影响结果，这正是全年回放与事件压力测试的价值。

## 项目解决的核心问题

| 企业问题 | 项目回答方式 |
| --- | --- |
| 新能源和储能装多少 | 多设备容量协同优化，输出风光、电池、电解槽、储氢等容量 |
| 方案经济性如何 | 年化投资、运行费用和总成本统一比较 |
| 是否真正低碳 | 位置法与零碳园区核算口径分列，外送电不自动抵扣 |
| 典型日方案全年能否运行 | 固定容量进行连续 8,784 小时滚动回放 |
| 电网故障时能保多少负荷 | 从实际事前状态启动确定性孤网与设备故障事件 |
| 结果能否审计复现 | run manifest 固定 Git 版本、输入路径和 SHA256，所有图表绑定同一 run_id |

## 项目亮点

1. **从规划到验证形成闭环**：代表日只负责选容量，全年回放负责证明容量可运行，孤网事件负责暴露保供短板。
2. **统一多能流物理模型**：电、热、氢母线逐时守恒，储电与储氢状态跨时段传递，规划与回放不维护两套相互矛盾的约束。
3. **把“低碳”和“韧性”变成可比较方案**：不是单纯调权重，而是设置明确的成本预算、保安负荷和孤网工程边界。
4. **结果口径诚实**：合成负荷不冒充实测，低碳型可行解不冒充严格最优，确定性事件不冒充概率可靠性评价。
5. **数据防污染**：旧数据、失败运行和正式结果物理隔离，正式入口只接受哈希固定的清单输入。
